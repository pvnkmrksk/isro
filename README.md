# ISRO Space Dashboard

An interactive, open-source dashboard visualizing India's complete space program — every satellite, every launch vehicle, every mission.

## Features

- **113+ Spacecraft** cataloged with detailed mission profiles
- **Interactive Timeline** spanning 50+ years from Aryabhata (1975) to present
- **Orbital Visualization** showing where satellites orbit in real-time
- **Launch Vehicle Families** — SLV, ASLV, PSLV, GSLV, LVM-3
- **Wikipedia Integration** — backstories pulled directly from Wikipedia
- **Satellite Spotting Guide** — learn how to spot ISRO satellites in the night sky
- **Customer Satellites** — foreign satellites launched by ISRO
- **ISRO Research Centres** across India
- **Fully Responsive** — works on desktop, tablet, and mobile
- **Zero Hosting Cost** — hosted on GitHub Pages

## Data Sources

- [ISRO API](https://github.com/AdityaAsopa/isro_api) by Aditya Asopa (MIT License)
- [Wikipedia](https://en.wikipedia.org) for spacecraft summaries
- [N2YO](https://www.n2yo.com/) and [Heavens-Above](https://www.heavens-above.com/) for satellite tracking

## Tech Stack

Pure HTML, CSS, and JavaScript — no build tools, no frameworks, no dependencies. Just open `index.html` in a browser.

## Development

```bash
# Clone the repo
git clone https://github.com/pvnkmrksk/isro.git
cd isro

# Open in browser
open index.html
# or use any local server
python3 -m http.server 8000
```
